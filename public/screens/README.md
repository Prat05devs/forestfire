# AgniVision screenshot slots

The landing page uses the supplied screenshots by their descriptive filenames:

- `home_overview.png`: hero foreground.
- `map-screen.png`: hero background and map feature.
- `official_advisories-weather.png`: official advisories feature.
- `recent_updates-uttarakhand.png`: Uttarakhand/destination section.
- `all-fire-alers.png`: observation activity log.
- `alert-detail.png`: detection detail and sharing view.
- `zoomed-map.png`: close map view.

Images are contained rather than cropped, preserving Google Maps branding. The alert-preferences screen keeps an intentional placeholder until that screenshot is supplied.

The supplied `public/logo.png` and `public/appicon.png` provide the current website identity.
